Cifrado César

Cada letra se corre k lugares en el alfabeto: Ek(x) = (x + k) mod 26. Escriba cualquier texto, elija la clave y vea girar el disco. Para descifrar se corre hacia atrás: Dk(y) = (y − k) mod 26.

En la figura: clic a la derecha o a la izquierda del disco para girarlo, rueda del ratón, + − y M para cambiar entre cifrar y descifrar. La bandeja muestra las últimas 16 letras del mensaje.

Operación

Se usan las 26 letras de A a Z: las tildes se quitan y la Ñ queda N. Espacios, números y signos no cambian. «Usar como mensaje» pasa el resultado arriba y cambia la operación, para comprobar que se recupera el texto.

Romper el cifrado sin conocer la clave

Se prueban las 26 claves. Para cada una se descifra y se comparan las letras obtenidas con las frecuencias del idioma: χ²(s) = Σ (O − E)² / E. La clave correcta deja el texto más parecido al idioma, así que da el χ² más pequeño. Se analiza el texto cifrado: 0 letras.

El idioma también se adivina: se prueba cada idioma con cada clave y gana la pareja con el χ² más pequeño. En nuestras pruebas con 400 letras se acertó el idioma entre el 96 y el 100 % de las veces, y la clave entre el 99 y el 100 %. Con 100 letras el idioma baja a entre el 77 y el 99 %.
